## Claude Code notes

- A folder's `CLAUDE.md` loads once you read a file in it, but its `.claude/rules/` and skills load only in a session
  opened on that folder. For code, open the session on `worm-battlegrounds-game/` or `worm-battlegrounds-gui/`; from here, read that
  folder's `AGENTS.md` and rules before editing it.
- Temporary files (builds, scripts, test places) go in the scratchpad, not in this repo.
