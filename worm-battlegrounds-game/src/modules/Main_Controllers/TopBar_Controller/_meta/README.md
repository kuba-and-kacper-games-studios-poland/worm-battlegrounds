# TopBar_Controller

The game's buttons in Roblox's top bar. It adds a button on the left of the TopBar module's bar: a gear (the System theme's `gear` icon, `rbxassetid://123765846716976`) opens and closes the `Settings` widget through WidgetManager.

| | |
| --- | --- |
| Folder | `src/modules/Main_Controllers/TopBar_Controller` |
| Runs on | Client |
| Uses | `I.TopBar`, `I.WidgetManager`, `I.Settings` (the Settings module's `GUI_NAME`) |
