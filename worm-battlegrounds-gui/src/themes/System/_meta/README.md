# System

The default theme and the base every other theme extends: dark Night and paper Light palettes in Builder Sans, soft light-grey outlines, one style file per control. A game restyles by extending it in its own theme (`Extends = "System"`, listing only what changes); System itself is never edited in a game's gui repo (`gui/repo.md`).

| | |
| --- | --- |
| Folder | `src/themes/System` (in the place: `UmeGui.Themes.System`) |
| Extends | nothing: the base theme |
| Format | `.claude/rules/gui/format.md` (Styles and tokens, Game themes) |

## Tokens

`Tokens.lua`, the values styles name:

| Group | What it holds |
| --- | --- |
| `Palette.Night`, `Palette.Light` | Color roles: `Background`, `Surface` (+ `Hover` / `Pressed`), `Border`, `BorderStrong`, `Text`, `TextDim`, `TextMuted`, `Inverse` (+ `Hover` / `Pressed`, `InverseText`), `Accent`, `Success`, `Warning`, `Danger`, `Favorite`, `Glow`, `Knob`, `KnobStroke`, `Track`, `Overlay` |
| `Swatches` | Color sets a `Swatches` or `ColorPicker` can name: `Warm`, `Basic` |
| `Font` | `Hint` (SemiBold), `Body` (Bold), `Title` (ExtraBold), all Builder Sans |
| `TextSize` | `Caption` 11, `Small` 12, `Body` 14, `Heading` 15, `Title` 17, `Icon`, `Symbol`, `SymbolSmall` |
| `Icons` | Icon name → white-on-transparent image id, tinted by controls; generated from `<art-tools>/icons/ume-gui` |
| `Radius` | `None`, `Small` 4, `Control` 6, `Card` 6, `Window` 8 |
| `Size` | Rows, controls, icon buttons, header, title, logo, grip, track, bar, knob, toggle, swatch, check, chip, the default window and the menu width |
| `Spacing` | `None`, `XS` 4, `S` 6, `M` 10, `L` 14, `XL` 18, `Buttons` 8 |
| `Stroke` | `None`, `Thin` 1 (divider lines), `Thick` 1.5 (outlines on containers, buttons and knobs) |
| `Motion` | `Fast` 0.08, `Default` 0.14, `Slow` 0.22 seconds |

## Styles

`Styles/<Control>.lua`, one per control plus `Menu.lua` (the right-click menu). Each has `Default` and its variants; every key a variant or node sets exists in `Default`.

| Style | Variants |
| --- | --- |
| Button | `Primary`, `Small`, `Danger`, `Ghost` |
| Card | `Subtle`, `Filled` |
| CheckItem | `Small` |
| Divider | `Strong` |
| Dropdown | `Small` |
| Grid | `Tight` |
| IconButton | `Ghost`, `Builder`, `Small`, `Wide` |
| Input | `Small` |
| Label | `Field`, `Caption`, `Heading`, `Title`, `Strong`, `Small`, `Fixed`, `Dim`, `Muted`, `Success`, `Danger`, `Warning` |
| ListCard | `Subtle` |
| Panel | `Padded` |
| Scroll | `Tight`, `Flush`, `List`, `Inset`, `Overlay` |
| Section | `Plain` |
| Segmented | `Small` |
| Stack | `None`, `Tight`, `Snug`, `Buttons`, `Loose`, `Bar` |
| Thumb | `Caption`, `Row`, `Banner` |

Chips, ColorPicker, Dialog, DropMarker, EmptyState, FileRow, Footer, Header, ListBox, ListItem, Menu, Progress, RangeSlider, Slider, Swatches, Tabs, Tile, Toggle, VectorInput, Viewport and Window have `Default` only.

## Generated

`Gamepad.lua` lists the gamepad button icons by pad (`Xbox`, `PlayStation`), icon style (`Color`, `White`, `Bold`, `BoldWhite`) and `Enum.KeyCode` name; `DPad` is the whole d-pad with nothing pressed. It is generated by `export_lua.py` in `<art-tools>/icons/gamepad-prompts` from `roblox-ids.json`: change the icons there and export again, never edit the file. A theme without its own `Gamepad.lua` uses its base's.
